## 3. CKM 高棉文尊榮語域與正統稱謂規範 (Tone & Honorifics)

1. **尊榮稱謂（Mandatory Honorifics）**：
   - 讀者尊稱：**`លោកអ្នក`**（尊敬的閣下/貴賓；嚴禁使用直白的 `អ្នក`）。
   - 團隊自稱：**`យើងខ្ញុំ`**（我們團隊/在下；嚴禁使用平輩的 `យើង` 或單數的 `ខ្ញុំ`）。
   - 零浮誇宣稱：嚴禁出現「第一」、「最強」、「神級」、「無敵」等廉價行銷詞。
2. **英文單字與工程術語的高棉文正統替換表 (English Substitution Dictionary)**：
   * 公開貼文正文內**嚴禁出現任何英文單字或縮寫**，一律替換為正統高棉文：

   | 英文詞彙 | 正統高棉文替換 | 說明 |
   | :--- | :--- | :--- |
   | `Catering` | **`សេវាកម្មម្ហូបការ`** / **`សេវាកម្មធ្វើម្ហូប`** | 外燴 / 宴席服務 |
   | `VIP` | **`ភ្ញៀវកិត្តិយស`** | 尊貴貴賓 |
   | `Buffet` | **`អាហារប៊ូហ្វេ`** | 自助餐 |
   | `Cocktail` / `Finger food` | **`អាហារសម្រន់ស្រាលៗ`** | 精緻冷盤點心 |
   | `Food safety` / `HACCP` | **`អនាម័យនិងសុវត្ថិភាពម្ហូបអាហារ`** | 食品安全與衛生標準 |
   | `FAQ` | **`សំណួរដែលសួរញឹកញាប់`** | 常見問題 |

3. **菜色與食材命名精確性 (Dish Naming Precision)**：
   - 荷葉飯必寫為 **`បាយខ្ចប់ស្លឹកឈូក`**（`ខ្ចប់` 代表包裹；嚴禁錯寫為 `បាយខ្ទប់`）。
   - 石斑魚對應為 **`ត្រីតុកកែ`**（Grouper；嚴禁誤譯為筍殼魚 `ត្រីដំរី`）。

## 4. CKM 四大不可逾越的憲法紅線（源自真實事故）

1. **白名單過濾外國文字，防止 Hanuman 字型排版崩潰 (Unicode Whitelist)**：
   * **事故紀錄**：泰文（如 `ควร`）、天城文、CJK 或韓文曾混入單字，導致讀者端排版成豆腐方塊。
   * **規範**：文案字元僅允許高棉文（`0x1780-0x17FF`）、高棉符號（`0x19E0-0x19FF`）與基本英數標點。嚴格過濾泰文、CJK 與天城文。
2. **絕對不准出現「絕對值承諾」**：
   * **事故紀錄**：曾上線過「`១០០%` 完全沒有隱藏費用」等無條件承諾，造成合約爭議。
   * **規範**：嚴禁寫出 `១០០%`、`គ្មានការចំណាយលាក់កំបាំង`（零隱藏費用）、絕對保證等詞。
3. **絕對不准公布「硬規格與底價」**：
   * **規範**：嚴禁在公開貼文公布保溫精確溫度、發電機 kVA、每桌確切底價或最低桌數，這些留給 Owner 依客戶預算私下報價。
4. **生圖 Prompt 一律指定 `no text`（嚴禁文字燒進圖裡）**：
   * **技術原因**：Windows 環境缺乏 raqm 庫，無法正確排版高棉文 COENG 附標。生圖 Prompt 一律指定 `no text`，文字全部由貼文正文呈現。

## 5. 標準交付規格（極速一分鐘發布）

AI Agent 每次生成 CKM Facebook 貼文時，**直接交付兩大產物，不輸出繁瑣 Prompt**：

1. **【1:1 奢華美食實拍圖片】**：Agent 直接調用工具生成 1:1 高畫質圖片，**自動通過 `Tools/image_cleaner.py` 脫敏清洗（0 C2PA、0 EXIF、0 AI 標籤）**，儲存至使用者 `Downloads/` 資料夾（無文字、無水印）。
2. **【公開發布文案】**：200~350 字元 100% 純高棉文（食材秘訣 + 星級火候 + 0 貼文外鏈 + 0 廢話）。
3. **【繁中意譯對照】**：供 Owner 快速審閱菜色細節與語意。
